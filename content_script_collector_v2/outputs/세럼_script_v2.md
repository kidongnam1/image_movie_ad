# Script Generator V2 — 세럼

## TOP 3 Hooks
1. **왜 어떤 날은 세럼를 발라도 피부가 금방 당길까요?** — 93.5점 (question)
2. **혹시 왜 어떤 날은 세럼를 발라도 피부가 금방 당길까요?** — 93.5점 (question)
3. **잠깐, 왜 어떤 날은 세럼를 발라도 피부가 금방 당길까요?** — 93.5점 (question)

## 30초 대본

### 0-3s · HOOK
- 대사: 왜 어떤 날은 세럼를 발라도 피부가 금방 당길까요?
- 자막: 왜 어떤 날은 세럼를 발라도 피부가 금방 당길까요?
- 화면: 세럼 제품을 빠르게 클로즈업. 손에 들고 카메라 쪽으로 보여준다.

### 3-8s · PROBLEM
- 대사: 세럼는 제품 자체만큼 내 피부 상태와 바르는 순서, 사용량을 같이 보는 게 중요합니다.
- 자막: 제품 + 피부상태 + 사용순서
- 화면: 세안 후 피부와 제품을 번갈아 보여주는 짧은 컷.

### 8-17s · DEMO
- 대사: 먼저 세럼 제형과 흡수되는 느낌을 손등에서 확인하고, 얼굴에는 소량씩 나눠 발라보세요.
- 자막: 제형 확인 → 소량 → 나눠 바르기
- 화면: 드로퍼/펌프에서 세럼 한 방울. 매크로 제형 촬영 후 볼에 소량 도포.

### 17-25s · PROOF_SAFE
- 대사: 바른 직후에는 끈적임, 밀림, 당김 같은 사용감을 확인하고 내 루틴과 맞는지 비교해보세요.
- 자막: 끈적임 · 밀림 · 당김 체크
- 화면: 손가락으로 피부 표면을 가볍게 터치하고 메이크업 전후의 사용감을 안전하게 비교.

### 25-30s · CTA
- 대사: 내 피부에 맞는 사용법인지 제품 정보를 확인해보세요.
- 자막: 제품 정보·사용법 확인
- 화면: 세럼 패키지와 제품 페이지를 연상시키는 깔끔한 엔드카드.

## CTA
내 피부에 맞는 사용법인지 제품 정보를 확인해보세요.
